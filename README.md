# PCAP Practice Projects

Practice exercises, mini-projects, and solutions written while preparing for the **PCAP – Certified Associate in Python Programming** certification.

**One step ahead after 100 days of code.**

## About

After completing a **100 Days of Code** Python journey, this repo marks the next step: moving from guided learning to focused certification preparation. The goal is to strengthen core Python fundamentals and build the depth needed to pass the PCAP exam — through hands-on practice rather than just theory.

Each file here is a small, self-contained exercise or project that targets a specific concept from the PCAP exam syllabus.

## Topics Covered

As the repo grows, exercises will cover the main areas of the PCAP syllabus, including:

- Control flow — loops and conditionals
- Data collections — lists, tuples, dictionaries, sets
- Functions, arguments, and return values
- Modules and packages (`random`, `math`, and others)
- Strings and string methods
- Exceptions and error handling
- Object-oriented programming basics

## Structure

Each project or exercise lives in its own file, named clearly so it's easy to find. File names follow Python's standard style — lowercase with underscores (PEP 8).

## Goal

Build consistent, practical Python experience while working toward the PCAP certification — and keep every step tracked here as progress.
